## R09-F02 — byte-backed candidate inspection

Based on exact HF01 commit `00e75b8f7510edd4b2868768b6af453522102bf0`; all six required hosted lanes passed on that predecessor. The optional picker review explicitly downloads one candidate (512 MiB transfer cap, 1 GiB expanded cap) into private disposable staging. Every redirect requires verified HTTPS; crossing an origin drops credentials and cookies. The existing Actions archive digest is checked before extraction. Android manifest and platform package metadata are inspected without invoking an installer. The existing bundle planner rejects ambiguous or incompatible configurations; unsupported feature-split layouts and filtered inventory are refused rather than guessed. The picker shows actual package, version code/name where available, minSdk, native library ABIs, split IDs, selected members, SHA-256 and observed certificate digests. Unknown split signing evidence and installed identity remain unknown, not attested. Certificate observation is not proof of attestation or installation.

The reviewed selection retains an in-memory exact release/asset digest binding, rechecked before normal extraction. Cancellation, stale selection and mismatch never launch an installer. Unreviewed candidates remain explicitly unverified and follow the existing normal install path. Preview bytes are discarded; normal download may transfer the asset again. The ordinary installer, signature, approval, downgrade and provenance gates remain authoritative. The conservative preview can refuse an APK with legitimate signing rotation; unknown data does not establish trust. Physical-device and live-source acceptance remain external.
